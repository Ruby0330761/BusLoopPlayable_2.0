5. 开场按体力选择专用模块：3/5 使用附件原设计，1/10 保留同套立体标题框、两侧星星、完整底框，分别以一颗居中/两排五颗重排并匹配文字。四档运行时按最大展示宽 620px 等比输出后无损 WebP 编码，RGBA 与对应派生 PNG 逐字节一致；原尺寸源 PNG 保留在素材目录。居中遮罩展示 2 秒、阻挡车辆点击，不点击跳过；首次进入/Retry 播放，连续换关不重播。加载、视频前贴、后台和编辑期间不扣展示时间；开场/救援锁输入期间倒计时暂停。
