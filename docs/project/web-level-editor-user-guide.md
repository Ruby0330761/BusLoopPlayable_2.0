# Bus Loop：网页关卡编辑器使用说明

本文档面向关卡设计人员，说明如何从新建空白关卡开始，完成车辆与地图机制摆放、乘客队列配置、深度重算、验证、保存和试玩。

# 入口

确保本地开发服务已经启动，然后在浏览器打开：

```text
http://127.0.0.1:5173/
```

如果开发服务使用了其他端口，以启动服务时显示的地址为准。

- 在右侧【场景调节】面板找到【关卡】区域。

- 【当前关卡】下拉栏会同时显示：

  - 已导入的 Unity 关卡。

  - 已保存的网页关卡。

- 选择已有网页关卡后，页面会重新加载并应用对应的关卡文件。

- 点击【编辑关卡布局】进入全屏关卡编辑器。

> 【导入关卡】用于导入文件名为 `level<number>.asset` 的 Unity 关卡，不是新建网页关卡的入口。

# 新关卡创建

进入关卡编辑器后，点击顶部【新建关卡】。

## 输入关卡编号和名称

- 【关卡编号】必须是大于 `0` 的整数。

- 保存时会自动生成关卡键名和文件名：

  - 输入 `40`，关卡键名为 `level40`。

  - 保存文件名为 `level40.json`。

- 【关卡名称】必填，最多 `80` 个字符，用于【当前关卡】下拉栏显示。

- 关卡编号和名称都不能与已有 Unity 关卡或网页关卡重复。

- 名称比较会忽略首尾空格、英文大小写和等价 Unicode 字符。

  - `Level 40` 与 `  level 40  `会被视为重名。

点击【创建】后，只会在编辑器中生成一个未保存的空白关卡。

**必须点击【保存】，新关卡文件才会真正写入项目。**

## 空白关卡的初始内容

新建关卡默认包含：

- 一个停车区容器。

- 两条空乘客队列。

- 默认地图缩放、网格和场景参数。

- 不包含车辆和其他地图机制。

# 主界面

关卡编辑器分为四个主要区域：

|区域|用途|
|---|---|
|顶部工具栏|新建、撤销/重做、重算深度、验证、保存、试玩、导入和导出|
|左侧工具栏|添加车辆和地图机制、排列、居中、转换闸门队列、按车辆 ID 定位|
|中央画布|选择、框选、拖动、旋转、缩放和观察关卡布局|
|右侧面板|关卡概览、关卡设置、画布设置以及所选车辆/容器的详细参数|

中央画布底部会显示当前操作状态，例如【验证通过】、【深度关系已重算】或【保存前需修复错误】。

# 从 0 到 1 的推荐配置顺序

建议按下面的顺序制作，减少返工：

1. 新建关卡并填写关卡编号、名称。
2. 配置关卡基础参数和画布网格。
3. 添加并摆放地图机制。
4. 添加车辆并设置颜色、座位和车辆机制。
5. 调整整体布局并检查车辆朝向。
6. 点击【重算深度】。
7. 配置乘客队列，使各颜色乘客数与座位容量一致。
8. 点击【验证】，修复所有错误。
9. 点击【保存】，将关卡写入项目并立即应用。
10. 在试玩中完整走一遍关卡。
11. 按需要导出 JSON、Unity、CSV 或 Excel 文件。

# 基础参数设置

未选中对象或同时选中多个对象时，右侧显示【关卡概览】和【关卡设置】。

## 关卡设置

|参数|说明|
|---|---|
|Unity ID|关卡数字 ID，新建关卡时默认与关卡编号一致|
|地图缩放|控制关卡布局映射到试玩场景时的整体比例|
|难度|普通、困难或超难|
|场景/传送带|当前关卡使用的场景或传送带名称|
|乘客模式|当前支持【固定顺序】|

## 画布设置

|参数|说明|快捷键|
|---|---|---|
|网格大小|网格吸附的步长|无|
|网格旋转|网格方向，范围为 `0°-360°`|无|
|网格吸附|拖动车辆后吸附到网格|`G`|
|载具吸附|靠近其他车辆时对齐 X/Z 坐标|`S`|
|辅助线|显示对齐辅助线|`A`|

# 画布操作

## 选择

- 鼠标左键单击：选中一辆车或一个地图机制。

- `Shift` + 鼠标左键单击：添加或取消一个对象的多选状态。

- 从画布空白处按住鼠标左键并拖动：框选多个对象。

- `Shift` + 框选：保留原选择并追加框选对象。

- 点击空白处：清除当前选择。

> 右侧详细参数面板只在选中单个对象时显示。多选主要用于移动、旋转、排列、复制、删除和镜像。

## 移动和观察画布

- 拖动选中对象：移动全部选中对象。

- 鼠标右键拖动、鼠标中键拖动或 `Alt` + 鼠标左键拖动：平移画布。

- 鼠标滚轮：缩放画布。

- `Space`：将画布位置和缩放恢复到默认状态。

## 旋转

- `Q`：将选中车辆或机制向左旋转 `15°`。

- `E`：将选中车辆或机制向右旋转 `15°`。

- `Alt` + `Q`：所有选中对象绕选区中心向左旋转 `15°`，同时改变坐标和角度。

- `Alt` + `E`：所有选中对象绕选区中心向右旋转 `15°`，同时改变坐标和角度。

- 右侧面板的【左转 15°】和【右转 15°】按钮：修改所选对象自身角度。

按住 `Alt` 连续旋转时，会保持本次选区的旋转中心；松开 `Alt` 后重新计算。

## 排列和定位

左侧【排列】区域提供：

- 【水平等距】：将选中对象对齐到同一 Z 坐标。

- 【垂直等距】：将选中对象对齐到同一 X 坐标。

- 【连线等距】：以首尾对象为端点，将选中对象均匀排列在连线上。

- 【全部居中】：将关卡中的车辆和地图机制整体移动到画布中心。

- 【转为闸门队列】：根据选中车辆的位置创建闸门队列，并将这些车辆加入该闸门。

在【定位】输入车辆 ID 并点击【定位】，画布会移动到该车辆并选中它。

## 其他快捷键

|快捷键|操作|
|---|---|
|`Ctrl` + `C`|复制选中对象|
|`Ctrl` + `X`|剪切选中对象|
|`Ctrl` + `V`|粘贴，自动分配新 ID，并向 X/Z 方向各偏移 `0.27`|
|`Ctrl` + `D`|复制并立即粘贴选中对象|
|`Ctrl` + `Z`|撤销|
|`Ctrl` + `Shift` + `Z`|重做|
|`Ctrl` + `M`|沿选区 X 方向镜像|
|`Ctrl` + `Shift` + `M`|沿选区 Z 方向镜像|
|`Delete` / `Backspace`|删除选中对象|
|`Ctrl` + `S`|保存关卡|

**网页关卡不会自动保存，关闭编辑器或新建其他关卡前必须确认已经保存。**

在数字输入框、文本框或下拉栏中编辑时，画布快捷键会暂时停用；先点击画布再使用快捷键。

# 添加车辆和地图机制

## 添加车辆

点击左侧【添加车辆】添加一辆车。

- 默认车辆为 4 座蓝车。

- 车辆 ID 自动使用当前最大车辆 ID 加 `1`。

- 在主关卡中添加时，车辆出现在当前画布中心附近并属于停车区。

- 正在编辑车库、运输带、闸门或升降舱内部时，新车辆自动加入当前容器。

选中单辆车后，可在右侧配置：

- X、Z 坐标和旋转角度。

- 颜色和座位数。

- 车辆机制。

- 隐藏、转向车状态。

- 所属容器和升降层。

## 车辆颜色

车辆和乘客使用相同的颜色 ID。下拉选项会显示颜色 ID、Unity 名称和中文名称。

|颜色 ID|Unity 名称|中文名称|
|---:|---|---|
|0|Blue|蓝|
|1|Green|绿|
|2|Pink|粉|
|3|Purple|紫|
|4|Red|红|
|5|Yellow|黄|
|6|Orange|橙|
|7|LightBlue|青|
|8|Brown|棕|
|9|DarkGreen|碧|
|10|DarkBlue|靛|
|11|PoliceCar|警车|
|12|FireTruck|消防车|
|13|Ambulance|救护车|
|14|Vip|VIP 车|
|15|Luxury|豪华车|

## 添加车库

点击左侧【添加车库】，然后选中车库：

- 双击车库，或点击右侧【编辑容器内车辆】，进入车库编辑界面。

- 在车库内多次点击【添加车辆】，车辆会自动按 Unity 车库规则排成一行，不会重叠。

- 车库内车辆顺序按从左到右排列。

- 点击画布上方【返回关卡】或按 `Escape`，退出车库并返回主关卡。

- 再次双击当前车库也可以退出。

退出后车库会保持选中，便于继续调整位置或角度。

## 添加运输带

点击左侧【添加运输带】后，会自动进入运输带内部编辑界面。

- 运输带专属的尺寸参数只有【出口宽度】，默认值为 `3.8`；X、Z 坐标和旋转仍使用通用字段调整。

- 运输带外框尺寸由编辑器自动计算：宽度为【出口宽度 + `2.23`】，长度固定为 `1.66`。

- 画布使用 Unity 的运输带纹理和黑色外框；灰色标记显示容器 ID，蓝色标记显示内部车辆数量。

- 在运输带内多次点击【添加车辆】，车辆会自动排成一行，不会重叠。

- 拖动运输带内车辆可以调整先后顺序，放开后整行车辆会自动重新排列。

- 点击画布上方【返回关卡】或按 `Escape` 退出；返回主关卡后，运输带内部车辆会隐藏。

**每个关卡最多只能配置一条运输带。**

## 添加闸门

闸门队列可以通过两种方式创建：

- 点击【添加闸门】，然后手动配置。

- 先选中一组车辆，再点击【转为闸门队列】。

闸门参数包括：

- 【路径形状】：直线或曲线。

- 【车辆间距】：默认 `0.1`，最小值为 `0.01`。

- 直线路径始终锁定，车辆会按照实际车长和车辆间距自动排列。

- 曲线路径解锁后，可以直接拖动车辆，把车辆位置作为曲线锚点。

- 勾选【显示曲线控制点】后，选中闸门中的单辆车，车辆两侧会显示黄色切线柄；拖动任一切线柄可以调整该处曲率和车辆朝向。

- 点击【刷新队列】，车辆会按照当前路径、实际车长和间距重新排布。

- 曲线重新锁定后，会保留当前平滑路径并限制车辆独立移动。

画布上的青色中心线表示车辆行驶路径，两侧青色边界表示闸门通道范围。移动或旋转整个闸门时，路径和内部车辆会一起变换。

## 添加升降舱

点击左侧【添加升降舱】后，会创建一个默认宽度 `1`、长度 `2` 的双层升降舱，并进入容器编辑界面。

- 可在右侧输入宽度和长度，也可拖动画布上的八个白色手柄调整四边和四角。

- 在右侧【编辑层】切换上层或下层；只有当前层可见并可编辑。

- 右侧会分别显示上层和下层的车辆数量。

- 任意一层为空时，升降舱显示红色外框；上下两层都有车辆时显示黄色外框。

- 当前层有车辆位于舱外时，右侧会显示提示。点击【在升降舱内居中】可将当前层车辆整体居中到舱内。

- 移动或旋转整个升降舱时，上下两层车辆会同步移动或旋转；调整舱体尺寸不会改变内部车辆坐标。

- 点击【返回关卡】或按 `Escape` 退出。主关卡只显示上层车辆，退出升降舱编辑后当前层会恢复为上层。

# 车辆机制配置

选中单辆车，在右侧【机制】下拉栏选择车辆类型。

|机制|需要配置的内容|
|---|---|
|普通车辆|颜色、座位、位置和朝向|
|隐藏车辆|隐藏状态；选择该机制时会自动勾选【隐藏】|
|双色组合|第二个组合颜色，组合颜色仅使用普通颜色 ID `0-10`|
|联动车头 / 联动车尾|关联车辆 ID、连接距离|
|扳手车 / 齿轮车|关联车辆 ID、扳手颜色|
|救护车|步数限制|
|消防车|倒计时|

## 隐藏车辆

- 选择【隐藏车辆】后，车辆会自动设置为隐藏。

- 也可以使用【隐藏】开关检查或调整状态。


## 救护车

在【步数限制】中填写允许的有效车辆操作次数。

- 其他车辆成功离场会消耗救护车步数。

- 救护车自身离场不会消耗自己的剩余步数。

- 剩余步数归零时会触发失败。

## 消防车

在【倒计时】中填写当前关卡需要的消防车时间限制。保存后必须通过试玩确认倒计时节奏和失败条件符合设计。

# 乘客队列配置

在未选中单个对象时，右侧【乘客队列】区域会显示每条队列的乘客数量。点击【打开队列编辑器】进入完整队列界面。

队列编辑器分为：

|区域|用途|
|---|---|
|乘客操作区|选择颜色和数量，添加、替换、复制、粘贴、删除、排序或修复乘客|
|队列编辑区|查看两条队列，选择、框选和拖动乘客|
|Passenger Flow 预览区|按顺序预览指定范围的乘客流|
|数据统计区|比较乘客数量、车辆座位容量和所选乘客数量|

## 添加乘客

1. 点击目标队列，使其成为当前队列。
2. 在【颜色】中选择乘客颜色 ID。
3. 在【数量】中输入需要添加的人数。
4. 选择【添加到队尾】、【插入到前面】或【插入到后面】。
5. 点击【添加】。

选择【插入到前面】或【插入到后面】时，以当前队列中最前面的已选乘客为插入位置；未选中乘客时会添加到队尾。

## 选择和移动乘客

- 单击一个乘客：单选。

- `Shift` / `Ctrl` + 单击：追加或取消选择。

- 在队列空白处或未选中的乘客位置按住鼠标左键并拖动：框选多个乘客。

- `Shift` / `Ctrl` + 框选：追加选择。

- 从任意已选乘客开始拖动：整体移动当前选择。

- 可在同一队列内调整顺序，也可拖到另一条队列。

- 放置提示线显示在乘客左侧或右侧；队尾的 `+` 表示放到队尾。

移动时会保持所选乘客之间原有的相对顺序。

## 替换、复制和删除

- 【替换所选】：将所有已选乘客替换为当前颜色。

- 【复制】/【粘贴】：复制并插入选中的乘客颜色序列。

- 【删除】：删除所有已选乘客。

- 点击数据统计区中的某个颜色：一次选中所有该颜色乘客。

## Passenger Flow 预览

- 【起始位置】：选择从第几个乘客开始观察。

- 播放按钮：自动向后推进预览位置。

- 【显示数量】：控制每条队列同时显示多少名乘客。

每条队列前 `8` 名乘客会标记为首次展示范围。

## 按车辆深度一键排序

点击【一键排序】会先按当前关卡摆放重算车辆深度，再按深度从小到大排列乘客。相同深度的车辆保持当前车辆列表顺序，每辆车对应的同色乘客连续排列。

排序不会增加或删除乘客，也不会改变每条队列的长度。双队列按以下实际出客顺序回填：

1. 队列 `0` 的前 `8` 名。
2. 队列 `1` 的前 `8` 名。
3. 队列 `0` 的剩余乘客。
4. 队列 `1` 的剩余乘客。

因此队列 `1` 的首次展示段会衔接队列 `0` 的首次展示深度，队列 `1` 的剩余段则从队列 `0` 队尾之后继续递增。数量不匹配时，先使用【一键修复】，再执行【一键排序】。

## 数量匹配和一键修复

数据统计区会分别显示：

- 每种颜色的乘客数量。

- 每种颜色的车辆座位容量。

- 两者是否正确、缺少或超出。

点击【一键修复】后：

- 多出的乘客会从队列尾部开始移除。

- 缺少的乘客会补到当前较短的队列。

**一键修复只负责数量平衡，不负责设计乘客出现顺序。修复后仍需人工检查队列节奏。**

## 队列编辑器快捷键

|快捷键|操作|
|---|---|
|`Ctrl` + `A`|全选全部队列乘客|
|`Ctrl` + `C`|复制所选乘客|
|`Ctrl` + `V`|粘贴乘客|
|`Delete` / `Backspace`|删除所选乘客|
|`Ctrl` + `Z`|撤销|
|`Ctrl` + `Shift` + `Z` / `Ctrl` + `Y`|重做|
|`Ctrl` + `S`|保存整个关卡|
|`Escape`|关闭乘客队列编辑器|

队列修改与主关卡共用撤销、重做和保存历史。

# 重算车辆深度关系

完成车辆和地图机制布局后，点击顶部【重算深度】。

- 编辑器会按照车辆朝向，重新计算每辆停车区车辆前方的阻挡对象。

- 结果写入关卡文件的 `vehicleDepthes` 字段。

- CSV 和 Excel 中的 `depth` 列表示该车辆记录的唯一前方阻挡关系数量。

以下情况发生后，应重新计算深度：

- 移动车辆或地图机制。

- 修改车辆或地图机制的旋转角度。

- 添加、删除或复制车辆。

- 修改车辆所属容器。

**建议把【重算深度】作为每次验证和保存前的固定步骤。**

# 检测关卡配置

点击顶部【验证】，检查当前关卡能否保存。

## 当前自动验证内容

- 容器 ID 是否重复。

- 车辆 ID 是否重复。

- 车辆座位数是否为 `4`、`6` 或 `10`。

- 车辆引用的容器是否存在。

- 联动车、扳手车和齿轮车引用的关联车辆是否存在。

- 每种颜色的乘客数量是否与车辆座位容量一致。

- 每个关卡是否最多只有一条运输带。

- 运输带出口宽度是否为有效正数。

编辑器还会给出以下提醒：

- 关卡中没有车辆。

- 停车区容器数量不是一个。

- 升降舱任意一层没有车辆。

- 升降舱当前编辑层存在舱外车辆。

验证失败时，画布底部会显示具体错误；保存也会被阻止。

## 仍需人工检查的内容

当前自动验证不能代替完整试玩。保存前还需要人工确认：

- 车辆和地图机制没有穿模或不合理重叠。

- 车辆朝向与预期开出方向一致。

- 车库、运输带、闸门和升降舱内车辆顺序正确。

- 乘客队列顺序符合关卡节奏，而不只是数量相等。

- 关联车辆配置符合设计，没有错误的头尾或扳手/齿轮配对。

- 关卡能够完整通关，特殊车辆的成功和失败条件正确。

# 保存、试玩和导出

## 保存到项目

点击顶部【保存】或按 `Ctrl` + `S`。

- 保存前会自动执行关卡验证；存在错误时不会写入文件。

- 新关卡保存到：

```text
artifacts/web-levels/level<number>.json
```

- 例如 `level40` 保存为：

```text
artifacts/web-levels/level40.json
```

- 再次保存已有网页关卡时，旧版本会先备份到：

```text
artifacts/web-level-backups/
```

- 备份文件名包含关卡编号和保存时间。

- 保存成功后，新文件会立即应用到试玩页面，并出现在【当前关卡】下拉栏中。

如果文件在编辑器外被修改，保存可能提示版本冲突。此时应重新打开关卡，确认外部修改后再继续编辑，避免覆盖他人的内容。

## 试玩

点击顶部【试玩】会把当前编辑状态临时应用到浏览器并重新加载页面。

**试玩不等于保存。**

- 已保存关卡：可以用试玩快速检查最新布局。

- 未保存修改：只存在当前浏览器的临时预览中，不会写入关卡文件。

- 页面刷新后仍可能看到临时预览，但换浏览器、清理浏览器数据或切换关卡后可能丢失。

需要长期保留的修改必须点击【保存】。

## 导出文件

顶部工具栏支持以下下载：

|按钮|文件|用途|
|---|---|---|
|JSON|`level<number>.json`|网页编辑文档备份或交换|
|Unity|`level<number>.asset`|Unity YAML 格式关卡数据|
|CSV|`level<number>.csv`|车辆/容器表格检查，包含车辆 `depth`|
|Excel|`level<number>.xls`|Excel 表格检查，包含车辆 `depth`|

导出文件由浏览器下载到浏览器默认下载目录，不会代替项目中的正式保存文件。

【导入 JSON】只接受与当前关卡键名一致的网页编辑文档。例如当前打开 `level40` 时，只能导入文档键名同为 `level40` 的 JSON。

# 退出编辑器

- 点击顶部右侧【关闭】返回试玩和场景调节界面。

- 如果存在未保存修改，编辑器会要求确认。

- 在车库或其他容器内部时，先点击【返回关卡】或按 `Escape` 回到主关卡。

- 在乘客队列编辑器中，按 `Escape` 只关闭队列编辑器，不会退出整个关卡编辑器。
