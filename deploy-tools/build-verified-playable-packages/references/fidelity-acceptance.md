# 资源保真与停止条件

## 自动检查

检查文件格式、参数和 manifest 一致性；缺失/重复/外部资源；图片尺寸、宽高比、透明通道和透明边缘；图片合集逐张反裁、位置、padding 和边缘扩展；三维物体轮廓、贴图位置、法线、切线、透明面、骨骼、动画和运行时错误；字体逐字体检查缺字、fallback、样式指标、字宽、行高、换行、按钮溢出、字重、斜体、可变轴、语言 shaping，并在图标字体声明码位时验证图标码位；配置全部 reachable pointer 的值；音频分类、时长、声道、采样率、码率、响度、峰值、首尾静音、编码延迟、metadata 和循环接缝；启动关键时间、关键阶段帧间隔/FPS、Long Task、可选内存、解码和控制台错误。`per-resource-v2` 字体覆盖报告缺少任一必需布尔结论时 fail-closed；旧报告缺少新字段时仅按旧契约只读兼容。编码后非 WAV 音频必须由锁定 FFmpeg 解码复探。没有项目批准阈值时只报告数据并保留人工门禁，不自动判通过。

## 人工确认

有损候选必须人工确认画面质感、文字与透明边缘、图片合集错图/串色、三维物体近景轮廓和动画中间帧、字体显示、配置驱动玩法、操作手感、节奏反馈、BGM 循环、SFX 瞬态和语音可懂度。自动保真和 A/B 入口准备完成后即可生成 Gate B；此时人工结论明确标为“待确认”。用户必须在 Gate B 的同一次回复中给出 A/B 结论与 `candidate-only` 或精确覆盖选择。没有明确人工结论不能进入平台构建。

Tinify 图片还必须逐图记录 `accepted|rejected|paused`。`accepted` 只表示候选具备 Gate B 资格，不等于已采用或写回；`rejected` 必须回到原图；`paused` 阻断当前 Gate B。像素敏感图片除自动像素指标外必须通过运行时语义、通道/色彩空间和必要的二维码/条码解码验签。

## 单变量与回滚

每个候选只改变一个试做变量，其他控制参数在 Gate A 内冻结；通过后登记新候选点，重建 exact artifact、更新账本并重新排序，失败则回到最近通过资源集。Gate B 覆盖前另建正式工程回滚副本。画面、动画、交互、音频、字体、配置、性能或可追溯性出现不可接受变化时立即回滚。

## 停止

下一步会改变确认效果、超过 Gate A 参数范围、收益很小但风险上升、新解码器净收益不为正或连续候选无净收益时停止继续减重，并在报告记录原因。
