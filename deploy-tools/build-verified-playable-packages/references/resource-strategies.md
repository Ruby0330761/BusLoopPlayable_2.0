# 资源优化策略

先按最终 artifact 净收益排序，先无损后有损，每个候选只改变一个参数；同时考虑解码、启动、内存和低端设备兼容。所有尝试必须落在 Gate A 批准的参数范围内。

## 图片

普通视觉图片默认首选 Tinify Developer API 的 `POST /shrink` 候选：只上传 Gate A allowlist 中的原图，保持原格式、宽高、宽高比和透明能力，不在 shrink 请求中混入 resize、降采样、quality、格式转换或 metadata 参数。Tinify 生成的候选始终写入 `candidateRoots`，保留原图副本；本地 FFmpeg `RESIZE`/`REENCODE` 继续作为独立、明确选择的备用候选。尺寸、格式、质量、metadata 仍分别审计、单独披露风险和授权，小图不得放大。

CTA、标题、文字、关键 UI、引导手、九宫格和透明边缘使用高风险 profile 与更严格参数/A-B，不得据此无条件 `KEEP`；法线图、数据图、像素遮罩、LUT、索引图、二维码和条码标记为像素敏感/高风险，Gate A 必须对每项确认上传用途与影响。结果除格式、尺寸、宽高比、透明通道、解码像素、色彩空间、通道值和透明边缘检查外，还必须绑定 `playable-image-semantic-verification-v1`；二维码/条码必须有解码结果一致证据。检查不通过时保持原图，不自动采用。不得用新素材替换保真问题。

Tinify 批次严格按 allowlist 顺序执行并记录脱敏 receipt。每个成功候选都要在统一 A/B 页面完成逐图 `accepted|rejected|paused` 决策；只有 `accepted` 项能进入 Gate B，`rejected` 项回到原字节，`paused` 阻断。额度明确不足时立即停止，剩余项为 `NOT_TESTED_QUOTA`；用户选择保持原图或生成只覆盖剩余项、且要求重新 Gate A 的本地备用提案。

尺寸、格式和质量必须逐图独立审计并分别作为单变量候选；尺寸无余量或受约束不能缩放时，仍输出独立格式/质量结论。每个风险特征必须绑定当前图片的具体用途证据；批量复制同一保护集合和通用证据会阻断新审计。小图不得放大。单页 A/B 同时提供整体、局部放大、透明棋盘和风险要求的真实场景。候选进入 exact artifact 后必须证明原图片 SHA 不再残留。

## 三维物体资源

三维物体资源指 FBX、GLB、GLTF 等网页玩法对象，不是 AI 模型。只有 Adapter/用途证据证明 runtime 支持时才转换格式；格式转换、紧凑存储和减面分开试做。保护轮廓、贴图位置、UV、法线、切线、透明面、薄片、骨骼和动画依赖。新增加载器、解码器和 fallback 代码计入最终净收益。Unity/raw/源 FBX 始终只读。

## 音频

- 先分类：`BGM`、`SFX`、`VOICE`，不得全部 MP3 共用一套默认参数。
- 声道、采样率、码率、格式、metadata 和裁剪分别测试；优先评估 mono 是否改变空间感或听感。
- Gate B 记录实际编码器、格式、码率、采样率、声道、响度、峰值、时长、metadata 和 A/B 入口。
- 检查瞬态、首尾静音、encoder delay/padding 和循环接缝。截短 BGM、删除音效或合并不同语义音效属于体验结构变化，不能自动执行。

## 图片合集与重复载荷

图片候选稳定且 runtime 能消费位置表后，才重建 rect、UV、sprite、padding、edge-extrude 和 manifest，并逐张反向裁切验证错图、串色、边缘污染、缩放和位置。builder receipt 必须列出全部输入 SHA；最终 artifact 中任一原始散图仍残留即阻断。文件级同 hash 只用于发现候选；不得删除项目文件。最终 HTML/ZIP 必须再次按内容 hash 扫描实际 occurrence，不能用中间目录去重结论代替。

## 字体与配置

新审计中，每个字体必须独立绑定 `fontUsage`：组件/角色、静态文案、动态来源及闭合证据、目标语言、样式上下文、fallback、字重、斜体、可变轴、shaping 语言与图标码位。不同字体不得共享顶层 `textCoverage` 或复制同一通用证据来生成结论；一个字体证据不完整时只把该字体标为 `UNSUPPORTED`，其他字体继续审计。候选必须保留 cmap、字形依赖、组合字符、字距、连字、字重、样式、可变轴和语言 shaping；缺字、fallback、字宽/行高、换行、按钮溢出、字重/斜体/轴、语言 shaping 或图标码位任一漂移都阻断。旧顶层 `textCoverage` 只读兼容，不升级为新审计通过。配置只按闭合的显式 JSON Pointer 引用集合生成候选；不得按字段名、关键词或“看起来没用”推断。数组索引语义无法安全保持时保守保留整个数组。

历史案例参数不能作为新项目默认值。连续候选无净收益、风险上升或新解码器扣除依赖后收益不为正时停止。
